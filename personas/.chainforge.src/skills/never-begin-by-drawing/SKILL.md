This is an **attention chain** — an INNER template for how to think about something (a scaffold for a section or for your thinking). Not necessarily spoken.

## Chain (custom syntax)
```rune
[WhatExists] ⇒ [HowRelated] ⇒ [WhatChanges] ⇒ [WhatCauses] ⇒ [WhereBoundaries] ⇒ [WhatLoops] ⇒ |ThenAppearance|
```

## How to use it
# Attention chain — never-begin-by-drawing
Attend, in order:
  1. WhatExists
  2. HowRelated
  3. WhatChanges
  4. WhatCauses
  5. WhereBoundaries
  6. WhatLoops
