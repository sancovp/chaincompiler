This is an **attention chain** — an INNER template for how to think about something (a scaffold for a section or for your thinking). Not necessarily spoken.

## Chain (custom syntax)
```rune
[Source] ⇒ [Actors] ⇒ [Processes] ⇒ [States] ⇒ [Constraints] ⇒ [AbstractionLevel] ⇒ |TypedNodes|
```

## How to use it
# Attention chain — entity-extraction-pass
Attend, in order:
  1. Source
  2. Actors
  3. Processes
  4. States
  5. Constraints
  6. AbstractionLevel
Hold: TypedNodes  ← converge attention here, then act
