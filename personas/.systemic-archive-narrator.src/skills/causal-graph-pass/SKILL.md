This is an **attention chain** — an INNER template for how to think about something (a scaffold for a section or for your thinking). Not necessarily spoken.

## Chain (custom syntax)
```rune
[Observation] ⇒ [CandidateCause] ⇒ [Confounders] ⇒ [Mechanism] ⇒ [TemporalOrder] ⇒ [RivalExplanation] ⇒ |ConfidenceEstimate|
```

## How to use it
# Attention chain — causal-graph-pass
Attend, in order:
  1. Observation
  2. CandidateCause
  3. Confounders
  4. Mechanism
  5. TemporalOrder
  6. RivalExplanation
Hold: ConfidenceEstimate  ← converge attention here, then act
