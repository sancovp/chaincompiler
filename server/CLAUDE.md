# server/ — the plugin's tool-server launcher

What the plugin's `.mcp.json` runs to start the self-interpreter (`DESIGN.md` §16):

| file | what it is |
|---|---|
| `launch.py` | the launcher, standard library only, run by `uv run --no-project`: it answers Claude Code's `initialize`, `tools/list` and `ping` at once and refuses `server/discover`, starts `si-server` from PyPI behind it through `uv tool run --compile-bytecode`, and passes every message through, as bytes, once that server has answered; every request it cannot deliver is answered with an error |
| `initialize.json` | the real server's own answer to `initialize` — its newest protocol version and its capabilities — which the launcher's early answer follows; generated by `scripts/build_server_tools.py`, never edited by hand |
| `tools.json` | the tool list the launcher answers with before the real server is up — generated from the real server by `scripts/build_server_tools.py`, never edited by hand; `--check` refuses a stale one of either file |

Its tests are `scripts/tests/test_server_launch.py`.
